**我建议下一步先不要急着调 LightGBM 参数。**  
先做这三件事，优先级按顺序：

1.  **先做稳健性验证**
    
    -   用同一套参数跑多个预测窗口，而不是只看 2026-01 到 2026-05。
    -   建议至少跑：
        -   \--min-prediction-date 20250101
        -   \--min-prediction-date 20250701
        -   \--min-prediction-date 20260101
    -   目标：确认 Rank IC、收益、回撤不是只在一小段时间有效。
2.  **先优化组合构造，降低换手**
    
    -   对比 Top20 / Top50 / Top100
    -   对比：
        -   每日调仓
        -   每周调仓
        -   排名缓冲，例如“新买入取 Top20，已持有只要还在 Top40 就不换”
    -   我预计这一块比继续加特征更值得先做，因为当前信号有，但换手过高。
3.  **把诊断直接写进报告**
    
    -   分月收益
    -   十分位收益
    -   每日保留/替换数量
    -   这样以后每次跑完，不需要再手工分析为什么结果好坏。

如果你同意，我下一步建议直接做一个“实验矩阵脚本”，专门批量比较：

-   TopN
-   调仓频率
-   排名缓冲
-   含成本/不含成本结果

这样比单次改一个参数更快看清楚：问题到底在模型，还是在组合规则。
